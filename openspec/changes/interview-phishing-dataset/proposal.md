# 면접 사칭 통화 평가 데이터 작성

사용자는 면접 상황의 사기 통화 100개를 JSON으로 요청했다. 각 통화는 `나`와 `피싱범`의 1대1 대화이며 50~100문장으로 길이가 달라야 한다. 발표 자료는 확인할 수 없어 그 내용을 적용했다고 주장하지 않는다.

초기 범위는 합성 사기 대본·정답 포함 JSON·정답을 뺀 평가 입력·오프라인 검사와 사용 안내였다. 후속 요청으로 비교용 정상 면접 **100건**과 사기·정상 각 100건의 **Plan1 실제 Jev 평가 및 confusion matrix**를 포함한다. 최초 후속의 50건 요청은 사용자가 100건으로 정정했다. 서비스 코드, 실제 음성, 다자 통화 런타임, Plan2 실행은 제외한다. 기존 KorCCVi 결과는 별도 보존한다.

완료 조건은 정상·사기 각 100건의 실제 JSON과 평가 입력 검사가 통과하고, 200건의 실제 모델 평가 결과·실패 수·confusion matrix 표와 이미지가 제공되는 것이다. API 실패를 정상/사기 예측으로 간주하지 않는다.

## 2026-11-14 후속: 새 면접 대본 평가

사용자는 기존 합성 200건의 100% 결과를 재검토하고 다른 대본으로 평가하도록 요청했으며, 실제 통화가 아닌 면접 상황의 새 합성 대본을 명시했다. 기존 생성기·직무 문답을 재사용하지 않은 대본 100건(사기·정상 각 50건)을 별도로 작성한다. 새 대본·라벨·입력 해시를 평가 전에 고정하고 같은 Plan1으로 실제 Jev를 호출한다. 기존 결과는 보존한다.

기존 50~100문장 조건을 재현하는 장편 평가가 아니라 8~12발화의 별도 면접 장면 평가다. 표본 수·길이·사례 구성과 모델 별칭의 시점 차이가 있으므로 점수 차이를 단일 원인의 개선·퇴보로 해석하지 않는다. 완료 조건은 중복·누출 검사, 실제 100건의 성공/실패와 혼동행렬, 오류 사례 및 한계의 기록이다.
