# 작성과 평가 입력 분리

[현재 서비스](../../../docs/architecture/overview.md)와 [입력 계약](../../../docs/design/mvp-flow.md)은 수정하지 않는다. 기존 실험은 JSONL 세그먼트와 시간 구간을 읽지만 이번 요청은 50~100문장 JSON이므로 별도 데이터셋으로 만든다. 기존 실험 로더와 호환된다고 표시하지 않는다.

[생성 도구](../../../experiments/build_interview_dataset.py)의 직접 작성한 20개 사기 유형을 5개 반응과 조합한다. 100개 직무에 서로 다른 문제·행동·결과 사례를 부여한다. 분야별 면접 질문을 섞되 사례 소개→문제→행동→결과의 순서를 유지한다. 사기 요구는 면접 초반·중반·후반에 나눠 배치하고, 중간에 직무 질문을 재개할 때에는 전환 문답을 둔다. 시드로 길이와 조합을 고정한다.

한 발화 항목에 한 문장을 두며 홀수 길이에는 지원자의 연속 발화를 하나 추가한다. 원본에는 역할·사기 정답·근거 위치를 담고 평가 입력에는 A/B와 대화만 담는다. A/B 대응은 절반씩 바꾼다. 초기 사기 데이터 생성에는 외부 모델 호출이 없다.

## 후속 정상 표본과 Plan1 평가

[정상 생성 도구](../../../experiments/build_normal_interview_dataset.py)는 기존 사기 원본의 해시를 확인하고 정상 100건을 작성한다. 같은 직무·경력·길이의 짝을 유지하며 사기 요구 8개 문답과 압박·종료부를 정상 채용 절차로 교체한다. 20개 정상 주제와 5개 종료 경로를 직접 작성한다. 데이터 생성은 API를 사용하지 않고 기존 사기 원본도 변경하지 않는다.

혼합 입력에는 무작위 순서의 중립 ID와 A/B 대화만 포함하며, 역할·라벨·짝 통화 ID는 별도 정답에 둔다. Plan1의 기존 CSV 입력으로 변환할 때 대화에는 A/B와 본문만 넣고 라벨은 별도 열에 둔다. 각 클래스의 화자 대응은 50/50이고 통화 길이 분포는 같다.

실제 평가는 기존 Plan1 코드를 바꾸지 않고 전체 대화를 1회씩 보내 실행한다. 기존 KorCCVi 결과는 보존하고 `results/interview_200/`에 예측 CSV·결과표·추가 집계 JSON·이미지를 저장한다. 같은 합성 면접의 변형이므로 일반화 성능과 독립 실측 평가로 해석하지 않는다. 상세 형식은 [정상·혼합 평가셋 안내](../../../datasets/interview_normal/README.md)를 따른다.

장점은 문장 수와 화자를 재현 가능하게 맞추고 정답 누출을 막는 것이다. 한계는 원형 문답이 여러 통화에 반복되고 반응이 신중한 지원자 쪽에 치우친다는 점이다. 100개 독립 실측 통화로 간주하지 않는다. 공통 형식은 [데이터셋 안내](../../../datasets/interview_phishing/README.md), 분석은 [합성 데이터 기록](../../../docs/analysis/interview-phishing-dataset.md), 검증은 [work](work.md)에 있다.

## 새 대본 작성과 동결 (2026-11-14)

[새 작성본](../../../datasets/interview_holdout/scenarios.txt)은 100개 상황별 대화를 직접 작성한 원본이다. [변환·검사 도구](../../../experiments/build_interview_holdout.py)는 기존 생성기를 import하지 않고 A/B와 중립 ID만의 inputs, 라벨·근거를 포함한 answers, Plan1용 CSV를 만든다. 기존 데이터는 중복 대조 대상으로만 읽는다. A/B를 클래스별로 균형 있게 교대하고 순서는 seed 261114로 고정한다.

같은 키워드라도 실제 정보 전달·자금 이동을 요구하는 경우와 면접 질문·가상 과제·수취 계좌 제출인 경우를 구분하도록 구성한다. 일반 정상 면접뿐 아니라 유료 교육 소개·보증보험·기숙사 공제 등 조건을 검토하는 상황도 포함한다. 정답은 합성 작성 의도이며 독립적 법률 판단이 아니다.

평가 전 run_manifest의 입력·정답·프롬프트·실행 코드 해시를 기록하고 기존 Plan1을 변경 없이 실행한다. 기존 응답 어댑터가 응답 model을 반환하지 않아 모델 버전은 확정할 수 없다. 예측·집계·PNG·검사 근거는 results/interview_holdout_100에 별도 저장한다. 세부 한계와 실행 근거는 [work](work.md)를 따른다.
