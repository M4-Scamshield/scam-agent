# GitHub 협업 템플릿과 공유 스킬

## 문제와 목표

이슈/PR 작성 시 변경 범위와 검증 근거를 같은 형식으로 남길 템플릿이 없다. 사용자는 aTopsMigrator 스킬을 참고해 추가하고 AI 설정을 기능별 로컬 커밋으로 정리하도록 요청했다.

## 범위와 완료 조건

버그/변경 Issue Forms, 기본 PR 양식, 공유 스킬과 Codex/Claude 안내를 추가한다. YAML 구조·스킬 메타데이터·문서 연결을 확인한다. 실제 이슈/PR 생성·push·merge는 이번 작업에 포함하지 않는다.

기준은 [Harness](../../../docs/harness/index.md)와 [작업 흐름](../../../docs/harness/workflow.md), 이번 [요구](spec.md)·[설계](design.md)·[작업](tasks.md)·[근거](work.md)다.
