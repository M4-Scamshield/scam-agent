# KorCCVi 실제 사기 통화의 유형별 수법 정리

## 문제와 목표

위험 요소 목록(R1~R9: 송금·인증정보·신분정보·앱 설치·명의 대여·압박·비밀 유지·사칭·채널 이탈)을 상식과 공식 안내로만 만들면 근거가 약하다. 사용자는 2026-11-15에 KorCCVi의 실제 사기 통화(금감원 공개 녹취)를 화자 표시와 함께 읽고, 유형별로 사기범이 어떻게 사칭하고 무엇을 요구하며 어떻게 압박하는지 정리하도록 요청했다. 목표는 목록의 각 요소가 실제 통화에 얼마나 나오는지, 목록에 없는 수법이 무엇인지 데이터로 보여 주는 것이다.

## 범위와 제외 범위

- 포함: KorCCVi v2 사기 706통화의 화자 표시 대본 생성, 고정된 지침에 따른 통화별 유형·수법 라벨링, 유형별 집계와 분석 문서, 유형과 관계없는 행동 특징(F1~F6)으로 다시 묶은 집계.
- 제외: 정상 통화(AI Hub) 분석, 사람 검수에 의한 라벨 일치도 측정, 서비스 코드·프롬프트 변경, 평가 데이터 작성.
- 원문은 재배포 금지 자료라 Git 제외 경로 `data/`에만 둔다. 저장소에는 지침·스크립트·집계·바꿔 쓴 예만 남긴다.

## 완료 조건

706통화 전부에 라벨이 있고 중복이 없으며, 유형별 수법 비율·첫 등장 위치·순서·새 수법 목록이 집계되고, 분석 문서에 결과와 한계(라벨러가 LLM, 화자 분리 오류, 편집된 일부 구간, 출처 단일)가 적혀 있다.
