# 설계 결정

선택의 이유·검토한 대안·trade-off와 결정 상태를 남기는 위치다. 전체 진입점은 [문서 지도](../index.md)다.

## 문서 목록

별도 결정 본문은 아직 없다. 사용자가 이미 확정한 방향은 [프로젝트 컨텍스트](../project-context.md)에 보존했다. State/Graph의 Q1~Q14는 [스펙의 결정 이력 진입점](../design/state-and-graph.md#결정-이력의-연결), 당시 선택·대안과 후속 데모 범위 축소의 근거는 [first-demo work](../../openspec/changes/first-demo/work.md)에 있다. 사용자가 채택한 선택과 위임에 따른 에이전트 세부 선택을 구분한다. 독립적으로 관리할 새 결정이 필요하면 해당 원문 근거를 연결한 결정 문서를 작성한다.

제안·채택·대체 상태를 구분한다. 에이전트의 추천이나 초안을 사용자 승인으로 기록하지 않는다. 결정이 채택돼도 실제 코드에 적용됐는지는 [아키텍처](../architecture/index.md)와 [OpenSpec change의 작업 근거](../../openspec/index.md)를 따로 확인한다.
