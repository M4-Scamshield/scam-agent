# 분석과 실험

기존 자산 조사·외부 API 확인·기술 실험·재현 자료와 결과의 한계를 남기는 위치다. 전체 진입점은 [문서 지도](../index.md)다.

## 문서 목록

별도 분석 본문은 아직 없다. 첫 데모의 API 없는 검사·실제 Gemini 성공/실패·리뷰 회귀 검증은 [first-demo work](../../openspec/changes/first-demo/work.md)에 조건과 실행 근거를 남겼다. 현재 구현의 범위는 [아키텍처](../architecture/overview.md), Harness 참고 저장소와 적용 범위는 [Harness 안내](../harness/index.md)에 있다. 같은 검증 기록을 별도 분석 문서에 복제하지 않는다.

새 분석에는 관찰한 대상·시점·방법·결과·한계·관련 설계를 적는다. 외부 API 문서 확인과 실제 API 호출 성공을 구분하고, Mock 결과를 실제 기관 검증 결과로 표현하지 않는다.
