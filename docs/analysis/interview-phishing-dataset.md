# 면접 사기·정상 합성 통화와 Plan1 평가

작성일: 2026-11-07. 대상: 한국어 면접 상황의 1대1 사기 100건·정상 100건.

사용자는 각 통화 50~100문장과 `나`·`피싱범` 화자 구분을 갖춘 JSON 평가 데이터를 요청했다. 언급한 중간발표 PPTX는 저장소에 없고 연결된 문서 세션도 없어 참조하지 못했다. 통화마다 화자 두 명이라는 구체적인 요청을 적용했다. 서비스의 실제 다자 통화·STT·동시 실행 기능을 구현하거나 검증한 작업은 아니다.

후속 요청에서 사용자는 정상 표본 수도 100건으로 정정했고 `experiments/Plan1-JevOnly`로 실제 평가한 confusion matrix를 요청했다. [정상·혼합 평가셋](../../datasets/interview_normal/README.md)을 추가하고 기존 Plan1 코드로 200건을 실제 Jev에 보냈다.

산출물·형식·재현 방법의 기준은 [데이터셋 사용 안내](../../datasets/interview_phishing/README.md)다. [생성 도구](../../experiments/build_interview_dataset.py)는 직접 작성한 20개 사기 시나리오·100개 경력 사례와 문답을 조합하며 외부 API를 호출하지 않는다. 정답 포함 원본과 A/B 화자를 쓰는 평가 입력을 따로 저장한다. 원본 화자 이름을 모델에 전달하면 정답이 노출되므로 평가에는 입력 파일의 발화만 사용한다.

## 확인한 결과

- 원본 100통화, 7,451문장, 통화당 50~100문장, 평균 74.51문장.
- 길이 51종, 화자 2명, 사기 유형 20종 각 5통화, 직무 100종, 분야 20종.
- 유형에는 교육·장비·조회 비용, 인증번호·카드·비밀번호, 원격제어, 계좌 제공, 송금·가상자산·상품권 과제와 위약금 사칭 등이 있다.
- 최초 명시적 근거 위치는 11~77번째 문장이다. 합성 작성 기준이며 실제 탐지기의 최초 경고는 아니다.
- 전체 대화 중복과 통화 내 동일 문장 반복은 없지만 다른 통화와 공유하는 문답이 있다. 고유 문장은 2,343개로 전체의 31.45%다.
- 거절·검토·공식 경로 확인·미결정·통화 종료의 다섯 반응을 각각 20건 포함한다. 실제 피해 성공률이나 전형적인 피해자 반응 분포를 반영한 표본은 아니다.

## 정상 표본과 실제 Plan1 결과

정상 통화는 같은 100개 직무·경력·문장 수를 유지하며 사기 요구·압박을 정상 채용 절차로 교체했다. 정상 100건도 7,451문장·통화당 50~100문장이다. 교육·장비·급여·계정·직무 과제·입사 검진·일정 변경 등 20개 채용 주제에 5개 종료 경로를 조합했다. 정상 고유 문장은 2,255개·30.26%다. 회사명·경력·면접 문답을 공유하는 짝 통화이므로 독립 실측 표본으로 해석하지 않는다.

Plan1 입력은 사기 100건·정상 100건을 섞은 200건이다. 모델에는 A/B 화자로 변환한 대화만 전달하고 정답·원본 역할·짝 통화 ID를 제외했다. 기존 전체 통화 1회·서비스 공통 프롬프트·choice verdict를 사용했고, 원본/정답/200건 예측을 다시 대조했다. 모델 결과를 본 뒤 데이터를 수정하거나 임계값을 조정하지 않았다.

| 실제 / 예측 | 사기 Yes | 정상 No |
|---|---:|---:|
| 사기 100건 | 100 (TP) | 0 (FN) |
| 정상 100건 | 0 (FP) | 100 (TN) |

성공 200건·실패 0건이며 Accuracy·Precision·Recall·F1·Specificity는 각각 1.0이다. 오경보율·미탐률은 0%다. P(Yes)는 사기 0.90~1.00, 정상 0.00~0.06이었다. 평균 왕복 지연은 약 0.244초, 입력 토큰 461,617개·출력 토큰 6,800개다. 설정은 `jev-latest`이고 기존 Plan1이 응답 model 필드를 저장하지 않아 정확한 모델 버전은 미확인이다. 비용 단가를 지정하지 않아 금액은 계산하지 않았다.

## 해석 한계와 후속

초기 사기 원본만으로는 오경보율을 측정할 수 없었지만 후속 정상 표본을 추가해 이번 합성 표본의 오경보율을 확인했다. 문답 원형을 공유하므로 무작위로 학습·평가에 나누어 독립 표본처럼 해석하지 않는다. 실제 음성, ASR 및 화자 분리 오류, 통화 시간은 없다. 독립 검수자에 의한 정답 합의·전체 대본의 자연스러움 평가는 수행하지 않았다. 생성 규칙의 전체 문답 원형과 50·100문장 통화 및 중간 길이 사례의 흐름을 직접 확인했다. 이번 정확도 100%는 준비한 합성 평가셋에서의 단일 측정이며 실제 통화 성능이나 독립 모집단 성능을 증명하지 않는다.

2026-11-14 후속으로 [새 면접 대본 100건을 작성해 재평가](interview-holdout-eval.md)했고 정확도 98%·정상 오탐 2건을 확인했다. 기존 결과와 파일은 보존했다. 발표 자료 대조·독립 사람 검수·실제 음성 조건·모델 버전 고정·반복 측정은 여전히 별도 범위다. 이번 요청은 CSV로 변환한 전체 통화를 기존 Plan1에 넣는 별도 평가다.
