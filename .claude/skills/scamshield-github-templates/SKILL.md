# ScamShield GitHub Templates (Claude Code)

이 스킬의 권위 있는 지침은 `.agents/skills/scamshield-github-templates/`에서 관리한다. 저장소의 단일 출처 원칙에 따라 여기서는 본문을 복제하지 않고 원본을 그대로 적용한다.

## 적용 방법

1. [.agents/skills/scamshield-github-templates/SKILL.md](../../../.agents/skills/scamshield-github-templates/SKILL.md)를 읽고 템플릿 유지·PR 초안 절차를 따른다.
2. 기존 양식을 사용·갱신한다: [버그 폼](../../../.github/ISSUE_TEMPLATE/bug_report.yml), [변경 제안 폼](../../../.github/ISSUE_TEMPLATE/change_proposal.yml), [PR 양식](../../../.github/PULL_REQUEST_TEMPLATE.md).
3. 개별 이슈 초안·등록은 [scamshield-create-issue](../scamshield-create-issue/SKILL.md)로 넘긴다.

요약: 이슈 폼·PR 템플릿을 저장소 실제 프로세스에 맞게 유지하고, 요청 시 PR 초안을 작성한다.
