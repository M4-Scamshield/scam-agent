# ScamShield Work Cycle (Claude Code)

이 스킬의 권위 있는 지침은 `.agents/skills/scamshield-work-cycle/`에서 관리한다. 저장소의 단일 출처 원칙에 따라 여기서는 본문을 복제하지 않고 원본을 그대로 적용한다.

## 적용 방법

1. [.agents/skills/scamshield-work-cycle/SKILL.md](../../../.agents/skills/scamshield-work-cycle/SKILL.md)를 읽고 그 절차(시작·재개 → 작업 → 마무리/인계)를 따른다.
2. 원본이 가리키는 문서([AGENTS.md](../../../AGENTS.md), [docs/index.md](../../../docs/index.md), [workflow.md](../../../docs/harness/workflow.md), [openspec/index.md](../../../openspec/index.md))를 함께 확인한다.
3. 마무리 시 [scamshield-docs-sync](../scamshield-docs-sync/SKILL.md)를 적용한다.

요약: 설계·구현·수정 작업을 문서와 근거로 시작/재개하고, 다음 세션이 이어받을 수 있게 기록을 남긴다.
