# KorCCVi 사기 통화 수법 라벨링 지침

`prepare.py`가 만든 `data/korccvi_tactics/batches/batch_NN.txt`의 통화마다 아래 형식의 JSON 한 줄을 `data/korccvi_tactics/annotations/batch_NN.jsonl`에 쓴다. 원문은 재배포 금지 자료라 `data/` 밖으로 옮기지 않는다. 저장소 문서에는 `paraphrase`와 집계만 쓴다.

## 읽는 법

- 대본 줄은 `<줄번호> [화자] 발화`다. 화자 A·B·C는 통화마다 따로 매긴 CLOVA 화자 분리 결과이며 틀릴 수 있다. 한 줄에 두 사람 말이 섞이기도 한다.
- `제목`은 FSS 원본 파일명이다. 실제 내용과 다른 경우가 있으므로 유형은 **내용으로만** 판단한다.
- 대부분 FSS가 편집한 일부 구간이다. 통화 전체가 아니므로 나오지 않은 수법을 추측해 넣지 않는다.

## 필드

```json
{"call_id": "vishing_9", "type": "수사기관 사칭", "impersonated": "서울중앙지검 수사관",
 "scammer_speakers": ["A"], "diarization_ok": true, "title_matches": false,
 "tactics": [{"code": "R8", "label": "검사·수사관 신분과 소속을 밝힘", "line": 1,
              "quote": "서울중앙지검의 박 수사관", "paraphrase": "중앙지검 수사관이라고 소개한다"}],
 "notes": ""}
```

- `type`: 아래 중 하나. 여러 개가 이어지면(예: 수사기관 → 금감원 연결) 주된 하나를 고르고 `notes`에 적는다.
  - `수사기관 사칭`: 검찰·경찰 등. 사건 연루·명의 도용 수사.
  - `금융당국 사칭`: 금융감독원·금융위원회 직원.
  - `대출빙자`: 저금리 대출·대환·신용점수 상향을 미끼로 상환금·수수료·예치금 요구.
  - `금융기관 사칭(대출 외)`: 은행·카드사·캐피탈의 이상거래·명의도용 확인 등.
  - `대포통장·인출책 모집`: 알바·대행을 미끼로 계좌·카드 제공, 현금 인출·전달 역할.
  - `지인·가족 사칭`, `기타`(유형 이름을 notes에), `판단불가`(너무 짧거나 맥락 없음).
- `impersonated`: 사칭한 기관·직함을 짧게. 없으면 "".
- `scammer_speakers`: 사기범으로 보이는 화자 표시. 역할 분담으로 여럿일 수 있다. 판단할 수 없으면 [].
- `diarization_ok`: 사기범과 피해자 말이 대체로 다른 화자로 나뉘었으면 true.
- `title_matches`: 제목이 내용과 같은 상황을 가리키면 true. 제목이 비었거나 일반적이면 null.
- `tactics`: 사기범 발화에서 확인되는 수법. **같은 code라도 내용이 다르면 따로**, 같은 내용이 반복되면 첫 등장 줄만 적는다.
  - `code`: 아래 R1~R9 중 하나. 어디에도 맞지 않으면 `NEW`로 두고 `label`에 새 수법을 적는다. 억지로 맞추지 않는다.
  - `label`: 이 통화에서의 구체적 행위를 한국어로 짧게(예: "현금을 찾아 직원에게 직접 전달하라고 함").
  - `line`: 처음 나온 줄번호. `quote`: 원문에서 40자 이하 그대로(검수용, data/ 안에만 남음).
  - `paraphrase`: 고유명·금액·숫자를 뺀 바꿔 쓴 한 문장(저장소 문서에 실을 수 있게).

## 수법 코드

| code | 정의 | 포함 예 |
|---|---|---|
| R1 | 송금·입금·현금 전달 요구 | 계좌이체, 현금 인출 후 전달·보관, 상품권, 가상자산, 상환금·수수료·예치금 |
| R2 | 인증·금융정보 요구 | 인증번호, OTP, 비밀번호, 카드번호, 보안카드 |
| R3 | 신분정보 요구 | 주민번호, 신분증, 주소, 직장 |
| R4 | 앱·링크 설치 유도 | 원격제어 앱, 보안앱·검찰앱 사칭, URL·파일 |
| R5 | 계좌·명의 대여 | 통장·체크카드 전달, 인출·전달책 역할, 명의 제공 |
| R6 | 긴급·압박 | 구속·처벌·불이익·대출 부결 위협, 시간 제한 |
| R7 | 비밀 유지·고립 | 말하지 말라, 은행원에게 거짓말 지시, 혼자 있는 곳으로 이동, 통화 유지 |
| R8 | 권위·신분 사칭 | 기관·직함·이름·사건번호 제시, 공문·규정 언급 |
| R9 | 공식 채널 이탈 유도 | 다른 번호·메신저·개인계좌·지정 장소로 유도 |
| NEW | 위에 없는 수법 | label에 구체적으로 |

자산 규모·잔액 질문, 녹취 동의 요구, 피해자가 할 말 대본 지시, 피해자에게 이득(보상·저금리) 약속 같은 것은 해당 code가 없으면 NEW로 적는다.
